Desktop guide

Greek desktop is a review and dictionary companion to the Android app.

Review

Reviews use the same Rust scheduling core as Android. Due cards come first; new cards follow the shared daily allowance.

Cards scheduled to return within 15 minutes are added to the end of the current queue, up to 60 cards in a session. They do not immediately replace the next card. If the only remaining card is due again soon, the session ends and tells you when to return rather than looping on that card.

The times on Again, Hard, Good and Easy are the actual schedule previews. A desktop review session is held in memory; finishing or reopening Review builds from the latest saved scheduling state.

Alphabet and curriculum

New learners start with the alphabet. Take the 24-question Alphabet Check on Curriculum, or choose I already know the Greek alphabet if you do not need that step. Both choices use the same gate and vocabulary unlocks as Android.

Chapter rows show separate learning and mastered counts. Learning reflects progress toward the next chapter; mastered means long-term retention. A locked row with an Unlock button has met its requirement.

Words, dictionary and sync

Words learned counts cards introduced into review. It does not count reader bookmarks or claim that every introduced card is mastered.

Dictionary searches use the bundled morphology lexicon when installed. Use the Android app for the reading experience and its additional study activities.

Sync & backup is in the small footer link on every screen. Sync and backup are optional; they use the same records and settings as the Android app.
